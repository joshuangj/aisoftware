# FormIQ

업무용 프로그램을 월 구독으로 소개하고 판매하기 위한 웹사이트입니다.

## 로컬 실행

```bash
npm install
cp .env.example .env.local
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 결제 활성화 전 필수 작업

1. 토스페이먼츠 가맹점 가입 및 정기결제(빌링) 계약
2. `.env.local`에 테스트 클라이언트 키 입력
3. 통신판매업 신고를 마친 뒤 신고번호 표시
4. 테스트 결제와 해지 흐름 검증 후 `NEXT_PUBLIC_PAYMENT_ENABLED=true` 설정

현재 구현은 결제 승인 화면으로 이동하는 첫 단계입니다. 자동 월 결제를 운영하려면 빌링키를 서버 DB에 암호화해 저장하고, 결제일에 청구하는 서버 작업과 웹훅 처리가 추가로 필요합니다. 비밀키나 빌링키를 브라우저 코드 또는 Git 저장소에 넣으면 안 됩니다.

## 카카오 오픈채팅

카카오톡에서 1:1 오픈채팅방을 만든 뒤 링크를 `NEXT_PUBLIC_KAKAO_OPEN_CHAT_URL`에 넣으면 사이트의 문의 버튼이 활성화됩니다. 공개 휴대전화는 스팸 위험이 있으므로 업무 전용 번호 사용을 권장합니다.
